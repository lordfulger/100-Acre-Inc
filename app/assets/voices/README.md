# Your own character voices

Record yourselves doing the characters and drop the files here, named after the character with a number: `pooh-1.m4a`, `pooh-2.m4a`, `piglet-1.m4a`, `eeyore-1.mp3`… (`.m4a`, `.mp3`, `.wav` and `.aac` all work; a phone's voice-memo app is perfect). Then run `npm start` (or `npm run voices`).

A character with recordings plays a random one of them whenever they'd speak (when you hire them, when their home gets a new look, when a hug or balloon arrives). Characters without recordings use the phone's built-in voice instead.

Names: `pooh`, `piglet`, `tigger`, `rabbit`, `owl`, `eeyore`, `kanga`, `robin` (Christopher Robin), `small`, `woozle`.

Keep each clip short — a few seconds.
