# Your own character pictures

Drop square pictures here (`.png`, `.jpg` or `.webp`) named after the character, then run `npm run portraits` (or just `npm start`, which does it for you). Any character without a picture keeps its drawn portrait.

| File name | Used for |
|---|---|
| `pooh.png` | Pooh, the honey pot, Bee Tree manager |
| `piglet.png` | Piglet |
| `tigger.png` | Tigger |
| `rabbit.png` | Rabbit |
| `owl.png` | Owl |
| `eeyore.png` | Eeyore |
| `kanga.png` | Kanga & Roo |
| `robin.png` | Christopher Robin |
| `small.png` | Small (Rabbit's smallest relation) |
| `bee.png` | the bee avatar |
| `woozle.png` | the Woozles |

Pictures are cropped to a circle, so keep the face in the middle.

**About the original drawings:** E. H. Shepard's illustrations in *Winnie-the-Pooh* (1926) and *The House at Pooh Corner* (1928) are public domain in the US. Coloured versions made later, Shepard's later redrawings, and Disney's versions are not. Outside the US, Shepard's drawings stay protected until 2047. Fine for a game the two of you play; check before publishing anywhere.
