# Pictures for the new content

Paste the **style** paragraph into the art chat first, then ask for each picture by its description. Save each file under the exact name given and send it to me (or drop it in the folder listed). I'll make the small versions and wire them in.

## Style (use for every picture)

> Original illustration in the style of a 1920s English children's storybook. Thin, slightly wobbly brown-ink line drawing with a soft, pale watercolour wash: muted honey yellows, sage greens, dusty pinks and sky blues, with lots of paper showing through. Warm cream paper background. Gentle and cosy, never scary. Don't copy E. H. Shepard's actual drawings or any Disney look. No text inside the picture unless the description asks for it.
