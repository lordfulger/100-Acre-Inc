# Pictures

All the pictures asked for so far are in the game:

- **13 album cards**, in `app/assets/portraits/cards/`. The small album versions in `app/assets/album/` are made by `node scripts/album-thumbs.js`, run from `app/`.
- **15 room paintings**, in `app/assets/rooms/`, shown when you go inside a home.

The minigames are drawn in code and don't need pictures.

## If you add more later

Use the same **style** paragraph as before:

> Original illustration in the style of a 1920s English children's storybook. Thin, slightly wobbly brown-ink line drawing with a soft, pale watercolour wash: muted honey yellows, sage greens, dusty pinks and sky blues, with lots of paper showing through. Warm cream paper background. Gentle and cosy, never scary. Don't copy E. H. Shepard's actual drawings or any Disney look. No text inside the picture unless the description asks for it.

- **Cards:** 800 × 960, a double-line brown border, and the name hand-lettered at the bottom.
- **Rooms:** 1200 × 840 and empty: clear middle floor, plain corners, and a window at the top centre.

**Optional:** the decorations you put up in rooms (rug, armchair, clock, teddy and so on) are still emoji. Ask if you'd like a list for painted versions.
